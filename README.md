This repository contains exercises and small projects that I use to refresh and improve my software development fundamentals.

## Goals

The goal of this repository is to strengthen my knowledge in:

* C# fundamentals
* Object-oriented programming
* Collections and data structures
* LINQ
* Exception handling
* Async/Await
* Git
* SQL
* ASP.NET Core
* Entity Framework Core
* Testing
* Docker
* Debugging

## Run the Project

Requirements:

* .NET SDK

Check the installed .NET version:

```bash
dotnet --version
```

Build the project:

```bash
dotnet build
```

Run the project:

```bash
dotnet run
```

## Training Approach

For each exercise I try to:

1. Understand the problem.
2. Develop a solution without immediately searching for an answer.
3. Compile and debug the implementation.
4. Understand any compiler or runtime errors.
5. Refactor the solution when necessary.
6. Document what I learned.
